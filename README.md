# Sistem Informasi Perpustakaan

## Deskripsi
Sistem informasi perpustakaan berbasis web.

## Teknologi
- PHP Native
- MySQL
- HTML
- CSS
- JavaScript

## Struktur Folder
- admin
- assets
- config
- includes
- scripts
- vendor

## Database
Database menggunakan library_db.

## Menjalankan Sistem
1. Jalankan Apache dan MySQL melalui Laragon.
2. Import library_db.sql ke MySQL.
3. Letakkan project pada folder web server.
4. Buka aplikasi melalui browser.
